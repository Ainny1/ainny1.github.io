# 🌸 Ainny1 — Pink Cybersecurity Portfolio

A mobile-friendly pink-and-lilac cybersecurity portfolio highlighting defensive security labs, practical Python work, and technical skills.

**Website (after merging and deploying):** https://ainny1.github.io/

## Features
- Responsive HTML/CSS with a floral-inspired cyber aesthetic
- Six linked GitHub projects and clearly scoped descriptions
- About, skills, and professional profile sections
- No external scripts, trackers, fonts, or build dependencies

## Preview and deploy
Open `index.html` locally in a browser. To publish, merge the pull request and verify **Settings → Pages → Deploy from a branch → main / (root)**.

## Accuracy
Project descriptions avoid claiming unverified test outcomes or production detection capabilities. Update them when additional labs are validated.
